## Hi, I'm Suresh 🦻

Part cyborg, thanks to my cochlear implant. I've been building software since 1993, and I'm profoundly deaf.
Reading is how I work, so I care about two things: text that doesn't get lost, and software that keeps
your data on your own machine.

Everything below is open source (Apache-2.0 or MIT), runs locally, and needs no account.
